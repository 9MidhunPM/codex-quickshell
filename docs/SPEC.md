# Public module acceptance brief

This release turns a local Codex status UI into a reusable integration.

1. Install alongside existing Quickshell setups without reading or modifying
   their shell, bar, theme, or compositor files.
2. Provide a compositor-neutral standard window, an optional status pill, a
   custom-host interface, and a separately imported Hyprland adapter.
3. Retain compact Home and directly detailed Usage/Agents tabs, accurate model
   provenance, exact credits, keyboard access, and visible stale/error states.
4. Use configurable/available terminal commands and work without mandatory
   systemd in the core runtime. Optional service activation must be explicit.
5. Keep monitoring metadata-only, with no credentials, conversations, model
   requests, payment operations, or automatic browser/terminal launches.
6. Check source and full public Git history for secrets and personal artifacts;
   publish only synthetic fixtures and public noreply commit metadata.
7. Publish a meaningful sequence of more than 40 focused commits, with automated
   tests, reproducible checks, public documentation, and honest support limits.

API balance retrieval is outside this release: official dashboard navigation is
provided without asking for keys or modifying billing. Universal compositor,
daemon-version, or custom-host compatibility is an objective to improve through
testing, not an assertion that every possible setup has been verified.
