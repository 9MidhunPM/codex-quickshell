# Changelog

## 0.5.0

Initial public reusable release.

- Compositor-neutral window, custom-host service and optional Hyprland adapter.
- Compact Home, complete Usage and Agents views, exact credits and per-thread models.
- Optional pill, partial themes, monitor selection and explicit instance IPC.
- Configurable terminal, monitor-only mode and detached actions without systemd-run.
- Additive installer with private manifest, ownership checks and rollback.
- Synthetic examples, privacy/history guard, Python and Qt CI, security documentation.

The initial public history separates implementation, tests, examples and
documentation into focused commits created for this release. It does not
represent a backdated history of earlier private development.
